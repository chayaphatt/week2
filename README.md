# Resume & Portfolio - Week 2

เว็บไซต์เรซูเม่และพอร์ตโฟลิโอส่วนตัว จัดทำขึ้นตามโจทย์การเรียนรู้เพื่อฝึกทักษะการสร้างเว็บไซต์ด้วย HTML และ CSS พื้นฐาน 

---

## ## Project Requirements

เว็บไซต์นี้พัฒนาขึ้นโดยอิงจากโจทย์ที่เน้นการจัดโครงสร้าง จัดวางเลย์เอาต์ และการตกแต่งด้วย CSS เบื้องต้น โดยมีข้อกำหนดหลักดังนี้:
* **โครงสร้างเลย์เอาต์:** คงรูปแบบโครงสร้างเว็บที่เป็นแถบกล่องสีชมพูและสีเหลืองพาดกว้างเต็มหน้าจอ พร้อมรูปโปรไฟล์และข้อมูลเรซูเม่
* **การจัดการลิงก์:** ใส่ลิงก์ช่องทางการติดต่อ (Facebook, Instagram และเบอร์โทรศัพท์) แบบลิงก์ข้อความธรรมดา ไม่ต้องทำปุ่ม (Button)
* **การตกแต่ง (Styling):** เน้นปรับแต่งฟอนต์ สีสัน และการเว้นระยะห่างให้อ่านง่าย สบายตา กลมกลืนไปในทิศทางเดียวกัน พร้อมเพิ่มมิติด้วยเงา (Soft Shadows) และมุมโค้งมนที่เหมาะสม
* **การจัดระเบียบเนื้อหา:** รวบรวมข้อมูลส่วนตัว งานอดิเรก ทักษะพิเศษ ความสนใจ และช่องทางติดต่อให้ครบถ้วน

---

## ### Tech Stack

* **HTML5:** สร้างโครงสร้างเนื้อหาและองค์ประกอบภายในหน้าเว็บ
* **CSS3:** ตกแต่งสีสัน ฟอนต์ จัดเลย์เอาต์ และเพิ่มเงาให้ตัวกล่องและหัวข้อ
* **GitHub Pages:** ใช้สำหรับเผยแพร่และแสดงผลเว็บไซต์ออนไลน์
